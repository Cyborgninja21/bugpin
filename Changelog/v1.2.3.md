# Changelog v1.2.3

### Maintenance

- Added `bun run repair-github-links` to preview and repair legacy screenshot and attachment links in existing open GitHub issues. Apply mode preserves other issue content, saves restricted local backups, and can be rerun safely.

### Fixes

- Screenshot capture no longer waits indefinitely for lazy images or image decoding. Image preparation continues after a three-second timeout so a pending image does not leave the reporter dialog closed.
- Screenshots and attachments uploaded to GitHub now use durable repository file links instead of temporary download URLs that expire in private repositories. Uploaded images appear as clickable links and respect the viewer's repository access.
- The corrected links are used when creating or syncing GitHub issues, including when uploaded files already exist in the repository. Existing issue links are updated on the next sync.
- Fixed two widget draft storage tests that referenced an undefined DOM variable and caused `make test` to fail.

### Security

- Updated dependencies to address vulnerabilities reported by `bun audit`, including TipTap 3.31.3, Hono 4.13.5, Nodemailer 9.1.1, and Sharp 0.35.4, with related editor and image-processing dependencies refreshed in the lockfile.
