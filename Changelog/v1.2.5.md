# Changelog v1.2.5

### Fixes

- Screenshot capture now works on pages built with Livewire or Alpine.js. Attributes such as `wire:navigate`, `wire:model`, `x-on:click`, `@click`, and `:class` made the captured image fail to load, so the widget showed "Failed to capture screenshot" whenever the Screen Capture API was turned off. BugPin now leaves these attributes out of its internal copy of the page while capturing. The live page is not modified, and pages without them capture exactly as before.
