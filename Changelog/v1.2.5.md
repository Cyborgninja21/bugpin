# Changelog v1.2.5

### Fixes

- Screenshot capture now works on pages built with Livewire or Alpine.js, including when the captured element is a same-origin iframe. Attributes such as `wire:navigate`, `wire:model`, `x-on:click`, `@click`, and `:class` made the captured image fail to load, so the widget showed "Failed to capture screenshot" whenever the Screen Capture API was turned off. BugPin now leaves attributes whose names are not valid XML out of its own copy of the page while capturing. Valid attributes are kept, including prefixed SVG attributes such as `xlink:href` whose namespace is declared.
- The fix only changes BugPin's own copy of the page. The live page is not modified, other scripts exporting the page at the same time are not affected, and pages without such attributes capture exactly as before.

### Maintenance

- Widget tests no longer depend on the order in which test files run. Tests now reset the widget language, clear timers and buffered reports left by other test files, and use a shared setup for Preact's render scheduling.
